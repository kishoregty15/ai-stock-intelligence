Telegram alerts

A Telegram bot needs a small secure backend. Never paste your bot token into this app or share it with anyone.

  1. In Telegram, open @BotFather, send /newbot and follow its steps.
  2. Save the bot token privately.
  3. Open your new bot and press Start. Send it a test message.
  4. In the next version, connect the token on a private backend and send alerts through Telegram's Bot API.
Telegram backend not connected in this demo

Install on Android

  1. Upload the supplied files to a trusted HTTPS static host (for example, your own GitHub Pages project or another static host).
  2. Open the hosted website in Chrome on Android.
  3. Tap Chrome menu ⋮ → Install app or Add to Home screen.
  4. Open it from your home screen.
