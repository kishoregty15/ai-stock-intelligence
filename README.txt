AI STOCK INTELLIGENCE V1 - ANDROID PROTOTYPE

This is a static, educational prototype. It does NOT connect to Groww or live NSE data.
It does NOT place trades. The scanner only evaluates manually entered values.

ANDROID INSTALL:
1. Host all files on a trusted HTTPS static host.
2. Open the hosted index.html in Chrome on Android.
3. Chrome menu > Install app / Add to Home screen.

GROWW:
Use official Groww Trade API documentation: https://groww.in/trade-api
Confirm current account eligibility, API pricing, scopes, rate limits and data permissions.
Never put API keys in browser JavaScript.

TELEGRAM:
Create a bot using @BotFather and press Start on your bot.
Do not put the bot token in this frontend. A secure backend is required to send alerts.
